# Directing Zodiac Family Drama

固定主题、固定时长（**15.0 秒**）的短片导演技能：**生肖拟人亲子家庭剧**。

- **三段顺序固定**：冲突发火 → 家长动手 → 孩子示好（和解）。不得调换、不得省略；每段的冲突双方、旁观者、动手家长、被打孩子、示好方向由**剧情槽位**指定（见第 4.1 节）。
- **角色一律生肖拟人**：家长 1–2 位（爸爸 / 妈妈 / 父母双方），孩子 1–2 个；每个角色选一个生肖（鼠、牛、虎、兔、龙、蛇、马、羊、猴、鸡、狗、猪）。
- **配音随生肖**：每个角色按自己所属生肖配声，全片一人一声线。
- **剧情与角色组合可变**：支持「两个角色起冲突 + 第三方旁观」结构；使用者可用提示词直接传入剧情，优先于内置示例（见第 4.1 节）。

输出是**已确认的分镜 + 3 段互相独立的 5 秒生成提示词**；可选再组装成片（见配置门）。

本技能从 `directing-stickman-videos` 继承导演工作流与提示词纪律，但**不继承它的十秒片段制、五段式长叙事、火柴人画风库和自动成片运行时**。不要把两个技能的分镜、画风提示词或时长规则混用。

## 1. 继承 / 改写对照

### 继承（from directing-stickman-videos）

- **技能打包方式**：一个 SKILL.md + `references/` + `assets/`，不做嵌套技能、不做多份安装。
- **首次使用说明**：交付物、适用内容、需准备的工具、工作流、可复制请求；用对话语言说明，一次性给出，不重复。
- **设置门（Setup gate）**：先收集必填项，缺项一次问完；不静默选比例/画风/角色。
- **导演工作流**：Phase A 提案 → 用户明确确认 → Phase B 提示词；改比例/时长/画风/台词/场景结构会作废旧确认，需重新确认。
- **独立提示词契约**：每条提示词自包含，角色卡整块逐字重复，禁止「same character」简写。
- **连续性**：上一段尾帧状态 = 下一段首帧状态；动作/道具/视线方向要有交接；首帧参考图按镜头给出。
- **音频纪律**：台词只作音频，禁止气泡框、字幕框；启用旁白时整片冻结一份完整声音档案并逐段逐字重复。
- **负面约束 / 画风纪律**：不写 hex/RGB/Pantone；不出现可见文字、logo、水印；禁止抽象液态形变，用具体肢体动作驱动。
- **可选角色三视图**：用户要专属角色时，先确认正/侧/背三视图；参考图是辅助，不是一致性保证。
- **诚实汇报**：技术检查 ≠ 用户验收；付费生成需授权；不自动发布；不虚构事实/数据。

## 2. 交付物形态

默认交付 **A · 提示词包**：

1. 15.0s 故事结构 + 三镜分镜表（起止时间精确到 0.1s，合计 15.0s，标明各段占比）+ 剧情槽位绑定（冲突双方/旁观者/动手家长/被打孩子/示好方向）
2. 3 条独立可复制的生成提示词（每条对应一个 5.0s 单元）
3. 角色卡（每个家庭成员的生肖、外观、拟人程度、声音）与首帧参考图指示
4. 拼接与剪辑说明（切点、尾帧→首帧交接、音效落点）
5. 台词/配音/旁白/字幕/BGM 的槽位与待处理清单（待确认 / 待核验 / 待补充）

可选交付 **B · 本地组装成片**（需先确认）：拿到 3 段生成素材后，按分镜拼接为 15.0s MP4，加配音/字幕/BGM/音效，输出 MP4 + 字幕文件 + 工程路径。启用前必须确认工具、授权与费用；不得把提示词包说成成片。

## 3. 工作流

1. **读剧情、参考图与配置**：先取使用者剧情（提示词传入优先，见第 4.1 节）；核对渲染风格、光照、构图；角色阵容以项目选定的生肖组合为准，不照搬参考图角色。
2. **过配置门**：按第 0 节收齐必填项；缺项一次问完。
3. **Phase A 提案**：出 15.0s 三段故事结构 + 分镜表 + 剧情槽位绑定（第 4.1 节）+ 角色卡（生肖/外观/声音）+ 台词/字幕/BGM 方案，**停下等明确确认**。改任何全局项都要重新提案。
4. **Phase B 提示词**：仅在当前 Phase A 被确认后，按 `references/prompt-contract.md` 输出 3 条提示词、首帧指示、拼接说明与验收清单。
5. **可选出片**：拿到素材后按需组装、检查、交付；用户确认成片满意后，才询问一次封面/发布包。

主题通过、进度压力或「你看着办」都不等于提案通过；旧版本确认不作数。

## 4. 15 秒叙事契约

### 4.1 剧情层（可配置；使用者输入优先）

**剧情槽位**（每个项目先把剧情映射到槽位，再绑定到角色槽位 P1/P2/C1/C2）：

| 槽位 | 含义 | 约束 |
|---|---|---|
| CA / CB | 冲突方 A / B | 必须是两个不同角色，家长或孩子均可 |
| OBS | 旁观者（1–2 人） | 冲突双方以外的家庭成员；某角色在某一拍转为行动者时，该拍不算旁观 |
| STRIKER | 动手家长 | 必须是家长角色 |
| STRUCK | 被打孩子 | 必须是孩子角色 |
| APPEASER | 示好方 | 默认 = STRUCK；也可由剧情指定其他角色 |
| TARGET | 示好对象 | 默认 = STRIKER；也可由剧情指定 |

**两个内置示例**（只代表「两个角色起冲突 + 第三方旁观」这类结构，不是全部组合）：

| 示例 | 结构 | 冲突 | 旁观 | 动手 | 被打 | 示好 | 最少角色 |
|---|---|---|---|---|---|---|---|
| A | 两个孩子吵架，爸妈在旁边看着 | C1 ↔ C2 | P1、P2（Part 1）；P2（Part 2–3） | P1（介入） | C1 | C1 → P1 | 2 个孩子 + 1 位家长（有 P2 更贴合「爸妈看着」） |
| B | 妈妈和孩子吵架，爸爸在旁边看着 | P1（妈妈） ↔ C1 | P2（爸爸） | P1 | C1 | C1 → P1 | P1 + C1 + P2 |

**使用者传入剧情（最高优先级）**：使用者用提示词/文字给出剧情时，以其为准，按槽位映射并做约束校验；**不得回退到默认剧情、不得擅自改剧情**。只有使用者未提供、也未选示例时，才用默认提案（示例 B），并在提案上标 `（待确认：剧情）`。

**输入入口**：在首次请求或配置门回复里直接写剧情即可，例如「两个孩子吵架，爸妈在旁边看着」「妈妈和孩子吵架，爸爸在旁边看着」「爸爸和儿子吵架，妈妈在旁边看着」；技能按槽位映射，不限于内置示例。使用者只给一句模糊剧情时，助手先映射成槽位并列出缺项（待确认：谁冲突/谁旁观/谁动手/谁被打/谁示好），不自行补全。

**冲突处理**：传入剧情若与 15.0s 三段结构、角色上限（2 家长 + 2 孩子）、「动手家长 / 被打孩子」约束或「第三方旁观」需求冲突，**指出冲突、请使用者确认取舍**，不擅自改契约、不自行删改剧情。

**组合清单**：（待确认：是否穷举所有角色组合，还是仅保留两个示例 + 使用者自行传入）——默认后者，不穷举。

### 4.2 三段与时长（固定，不得改动）

- **三段固定，各 5.0s**（各占 33.3%，取整；按秒计为 5.0 / 5.0 / 5.0 = 15.0s）：
  1. `0.0–5.0` 冲突发火：CA 与 CB 爆发冲突；OBS 旁观反应
  2. `5.0–10.0` 家长动手：STRIKER 动手打 STRUCK（非写实）；OBS 反应
  3. `10.0–15.0` 孩子示好：APPEASER 向 TARGET 示好（默认 STRUCK → STRIKER）；OBS 边缘
- 全片只拍**一个连续场景**，不换景、不跳时间。
- 第 1 秒观众必须看懂「冲突双方是谁、谁在冲谁发火」。
- **动手段按非写实处理**：用遮挡、剪影、画外动作或一次短促音效交代，不展示击打接触点、伤痕、红肿，不做哭嚎特写、不慢放、不重复；默认提案为「手掌/前爪一挥、非写实带过」，可改道具或推搡（待确认：动作方式）。
- **示好段**停在示好动作与家长的反应上；不做价值判断、不加字幕结论、不放「原谅」大字；默认提案为拉住家长的手，备选递小物件（待确认：示好方式）。
- 默认按**无台词**设计，靠表情、肢体、音效叙事；台词为可选槽位（见 `references/storyboard-15s.md`）。有台词时，台词只作音频，且必须按该角色的生肖声线配。
- 出场角色（1–2 家长 + 1–2 孩子；要「第三方旁观」需 ≥3 人）都要有动作与反应，禁止站桩；不擅自新增角色。
- 全片 15.0s，分镜起止时间加总必须**精确等于 15.0s**；每段 5.0s 内两拍，拍点见分镜表。

## 5. 生成单元与时长规则

- 默认：3 段 × 5.0s（0–5 / 5–10 / 10–15）。
- 工具只支持 8s：按 8s 生成，取前 5.0s 使用，多余 3s 作余量/转场；**不得**把 15s 改成 16s 或 24s。
- 工具只支持 4s/6s：优先 6s 生成再裁；仍无法覆盖时，先向用户说明并重排单元，不得静默改时长。
- 每段提示词里写明「约 5 秒」与精确的两拍时间；提示词外再给拼接表。

## 6. 画风与一致性

- 画风以用户参考图为准，完整锁在 `references/style-lock.md`；每条提示词重复整段画风块 + 该段可见角色的完整角色卡。
- **角色卡按项目生成**：生肖、体型与拟人程度、主色与纹样、面部特征、服装/配饰、声音，逐字复用；同一家庭可混搭不同生肖。
- 角色卡一旦确认，全片禁止换生肖、换主色、换年龄、换拟人程度；镜头间只变表情、姿态、视线与手势。
- 参考图只作渲染风格与生肖拟人的示范，**不是固定阵容**；默认提案直立拟人以便手势表演，若沿用参考图四足需改写动作（待确认：体型方案）。
- 服装/配饰默认不穿衣、仅必要配饰（待确认）；确认后写入角色卡。
- 首帧参考图优先：每段用已确认的角色图/首帧图作参考输入；工具不支持参考图时说明限制，走纯文本路径并提醒一致性风险。
- 生成后按 `references/prompt-contract.md` 的验收清单逐条核对；技术通过不等于用户满意。

## 7. 配音说明（按生肖配声）

- **一人一生肖一声线**：每个角色先定生肖，再按该生肖的声音特征选声线；同一角色全片只用一个声线，音色/音高/语速/口音固定，不随情绪换人。
- **依据**：以该生肖动物的自然发声特征做拟人化（鼠吱叫、牛哞、虎吼、马嘶、羊咩、蛇嘶、猴叫、鸡啼、狗吠、猪哼）；不得使用与该生肖无关的通用人类音色。
- **未试听前不确定**：具体音色、语速、口音由试听确定并记录（待核验：provider/model/voice ID 是否可用）；不得凭空编造音色参数。
- **缺乏稳定声源**：龙为神话生物，无真实发声；兔极少发声——这两类标（待补充：参考声源 / 用户确认），不给默认声线。
- **无台词时**：呼吸、叹气、哭腔、鼻音也按该角色的生肖声线处理，不用通用旁白嗓。
- **旁观者（OBS）**：若有劝架/反应台词或叹气，按其本人生肖声线，不因「旁观」换嗓。
- **旁白（若启用）**：单独选一个音色，不占用任何角色的生肖声线；旁白语言（待确认）。
